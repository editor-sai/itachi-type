# Itachi Type

A clean, hacker-style typing speed test website built using **HTML, CSS, and JavaScript**.

## 🚀 Live Website
👉 https://editor-sai.github.io/itachi-type/

## ✨ Features
- Typing speed test
- Practice mode
- Clean dark hacker UI
- Simple & fast
- Works on mobile and desktop

## 🛠️ Built With
- HTML
- CSS
- JavaScript
- GitHub Pages (Hosting)

## 📌 How to Use
1. Open the website
2. Click **Type Testing** or **Practice**
3. Start typing and improve your speed 🎯
